Freshcart

Freshcart is a frontend-focused e-commerce project built with React and TypeScript.

## Features
- Product listing
- Add to cart functionality
- Cart state management
- Responsive UI

## Tech Stack
- React
- TypeScript
- CSS / Tailwind (hvis brukt)

## What I learned
- Component-based architecture
- State management
- Working with props and reusable components
- Structuring a frontend project
