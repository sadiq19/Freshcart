# Freshcart

Freshcart is a frontend-focused e-commerce web application built with React and TypeScript.  
The goal of this project is to practice building a real-world frontend application and improve my understanding of how modern React apps are structured.

The project is still a work in progress and is being developed step by step as I continue learning and adding new features.

---

## Current Features

- Product listing
- Add to cart functionality
- Cart state management
- Responsive layout for different screen sizes

---

## Tech Stack

- React
- TypeScript
- CSS / Tailwind CSS

---

## What I’ve Worked On So Far

So far, my main focus has been on the frontend structure of the application. I’ve spent time breaking the UI into reusable components and making sure the project is easy to understand and extend.

I’ve also worked on managing state for the shopping cart, passing data through props, and keeping components clean and focused on a single responsibility. A lot of the work has been about learning best practices and getting comfortable with how React applications are organized.

---

## What I’ve Learned

- How to structure a frontend project using React
- Working with component-based architecture
- Managing state and sharing data between components
- Writing reusable components with props
- Improving responsiveness and overall UI flow

---

## Next Steps
